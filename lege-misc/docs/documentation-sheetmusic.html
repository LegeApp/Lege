Lege Sheet Music Edition

Prepare scanned scores and songbooks for clear, comfortable viewing on a computer, tablet, or compatible document reader.

Getting started

  1. Select Add File for one or more PDF/ZIP files, or to add every PDF in a folder. Select Add Folder for one book stored as a folder of page images.
  2. Check the page range, resolution, output format, and binarization setting.
  3. Select Process. You can add several books before starting; they will be processed in order.

Unless you choose another output directory, each finished file is saved beside its source.

Choosing an input

You can use:

  • PDF songbooks and scores.
  • ZIP files containing numbered JP2, JPEG, PNG, or other supported page images.
  • Folders containing JP2, JPEG, PNG, TIFF, BMP, PBM, PGM, PPM, or PNM images.

Image filenames should sort into reading order. Names such as page_001.jp2, page_002.jp2, and so on work well.

You can also drag PDF files, ZIP files, PDF folders, and image folders onto the window. A dropped PDF folder adds each PDF as a separate queue item.

Using Archive.org downloads

If an Archive.org item offers a JP2 ZIP, download it and add the ZIP directly. There is no need to extract all the page images yourself.

Output settings

Page Range

Leave this blank to process the whole book. Enter one page, such as 7, or a range such as 7-25.

Target Resolution

The default height is 1600 pixels, which is a good starting point for desktop and tablet viewing. Page proportions are preserved automatically.

  • Use 1200 for a smaller file when fine detail is less important.
  • Use 1600 for general desktop viewing.
  • Try 2000–2400 for large displays, frequent zooming, or scores with very fine notation.

You may also enter fixed dimensions, such as 1600x1200. A single height is usually the better choice because it preserves the shape of each page.

Output format

  • PDF is the best choice when the file must open on almost any computer or tablet.
  • DjVu can produce smaller files and works well in applications such as KOReader.

Choosing a binarization mode

Binarization turns the page into clean black notation on a white background. Start with Default adaptive and change it only when the result needs improvement.

Default adaptive

Recommended for most scans. It handles paper shading and uneven lighting without requiring another setting.

Custom adaptive

Use this when faint staff lines or notes disappear, or when too much paper texture remains. A lower K factor keeps more faint detail; a higher K factor produces a cleaner background.

Fixed threshold

Useful for clean pages with even brightness. A higher threshold keeps more gray detail and may also keep more paper noise. A lower threshold produces a cleaner page but can remove faint marks.

Heavy model

Try this for badly faded, stained, or uneven pages when the other modes cannot recover the notation satisfactorily. It takes longer to process.

Check a short page range before processing a very large book. This makes it quick to compare resolution and binarization settings on the most difficult pages.

Queue, progress, and results

  • Queue shows the sources waiting to be processed.
  • Log shows completed jobs and errors.
  • Cancel stops the current run.

This edition prepares the appearance of musical notation. It does not add searchable text or attempt to recognize the music itself.

If something goes wrong

  • If a folder is rejected, make sure supported page images are present and named in reading order.
  • If faint notation disappears, try Custom adaptive with a slightly lower K factor or increase the resolution.
  • If the background is dirty, try a slightly higher K factor or a lower fixed threshold.
  • If processing fails, open Log to see which source caused the error.

Your documents are processed on your computer. Lege does not upload the page images.
